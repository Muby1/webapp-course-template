# かんたんタスク

プログラミング初心者向けのWebアプリ開発講座で使う、タスク管理アプリ「かんたんタスク」のリポジトリです。タスクの一覧表示・追加・完了の切り替え・削除ができる、HTML・JavaScript（フロントエンド）とExpress（バックエンド）、PostgreSQL（データベース）で作られたアプリです。

## 手順書

各章の進め方は、こちらのリポジトリにまとまっています。事前課題からブックマークしてください。

https://github.com/Muby1/webapp-course-docs

## ブランチ一覧

このリポジトリには、講座の進み方に合わせて次のブランチがあります。
詰まったときは、該当する章の`-start`ブランチに戻ってやり直せます。

| ブランチ | どの章の、どの時点か |
|---|---|
| `main` | 第6章の開始時点（`ch06-start`と同じ内容） |
| `ch06-start` | 第6章の開始時点 |
| `ch06-end` | 第6章の終了時点 |
| `ch07-start` | 第7章の開始時点 |
| `ch07-end` | 第7章の終了時点 |
| `ch08-start` | 第8章の開始時点 |
| `ch08-end` | 第8章の終了時点 |
| `ch09-start` | 第9章の開始時点 |
| `ch09-end` | 第9章の終了時点 |
| `ch10-start` | 第10章の開始時点（中身は`ch09-end`と同じ） |
| `ch10-end` | 第10章の終了時点（中身は`ch09-end`と同じ） |
| `ch11-start` | 第11章の開始時点（中身は`ch09-end`と同じ） |
| `ch11-end` | 第11章の終了時点 |
| `ch12-start` | 第12章の開始時点（中身は`ch11-end`と同じ） |
| `ch12-end` | 第12章の終了時点（中身は`ch11-end`と同じ） |
| `ch13-start` | 総仕上げ（第13章）の開始時点（＝期限日機能のない完成版。中身は`ch11-end`と同じ） |

**中身が同じブランチについて**：第10章・第12章では、コードを書き換える課題がなく（画面の文言などの自由な変更のみ）、GitHubの操作そのものを学ぶ章のため、`-start`と`-end`でコードの中身は変わりません。ブランチ名だけが用意されているのは、章の区切りをはっきりさせ、迷ったときに正しい時点へ戻れるようにするためです。
